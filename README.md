# Team Task Manager

A full-stack web application for creating teams, managing tasks, assigning work, and tracking task progress.

## Tech Stack & Libraries

**Frontend**
- React – UI development
- Vite – Development and build tool
- React Router – Navigation
- Axios – API requests
- Tailwind CSS & DaisyUI – Styling and UI components
- Lucide React – Icons
- React Hot Toast – Notifications

**Backend**
- Node.js & Express.js – Server and REST API
- MongoDB & Mongoose – Database
- Passport & Passport Local – Authentication
- Express Session & Connect Mongo – Session management
- bcryptjs – Password hashing
- express-validator – Input validation
- CORS & dotenv – Cross-origin requests and environment configuration

## Features

- User authentication and sessions
- Team creation and management
- Task creation and assignment
- Task status tracking
- Team-based access control

## Setup

1. Install dependencies in both `Frontend/` and `backend/`.
2. Configure environment variables in `.env`.
3. Start the backend and frontend development servers.
